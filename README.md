# The Barboza Nutrition System — LP PT

Página estática pronta para GitHub/Netlify.

## Antes de publicar
Abra `script.js` e substitua:
`COLE_AQUI_O_LINK_DO_CHECKOUT_R37`

pelo link exato da oferta Hotmart de lançamento a R$37.

Não usei automaticamente o checkout base porque ele pode estar associado ao preço normal de R$47, enquanto esta página anuncia R$37.

## Estrutura
- index.html
- styles.css
- script.js

No GitHub, mantenha os três arquivos na raiz do repositório.
No Netlify, site estático: sem build command.
